# Client / partner logos

The "Banks and financial institutions we've worked with" / "In good company"
section (on the Home and About pages) loads logos from this folder. Files are
referenced in `content/clients.ts`.

## Files

| File | Brand | Source |
|---|---|---|
| `bdo.svg`        | BDO Unibank            | supplied SVG |
| `rabobank.svg`   | Rabobank               | supplied SVG |
| `al-baraka.svg`  | Al Baraka              | supplied SVG |
| `hdb.svg`        | HDB Financial Services | supplied SVG |
| `eastwest.png`   | EastWest               | **ACTION: save the EastWest PNG here** |

Until `eastwest.png` is present, the EastWest cell shows the brand name as text
(no broken image). Save the EastWest logo you shared as
`public/logos/eastwest.png` and it appears automatically.

To add, remove or reorder brands, edit `content/clients.ts`.
