# Leadership photos

The "Brains behind Avenza" section on `/about` loads each leader's photo from
this folder. Until a file is present, the card shows a branded monogram (initials
on an orange gradient) — so the section always looks finished.

## Add the three photos

Save each headshot here with the **exact filename** below (JPG or PNG works if you
keep the `.jpg` name, but JPG is preferred). Square or 4:5 portrait, ideally
≥ 800 px, subject centred toward the top:

| File | Person | Role |
|---|---|---|
| `mahesh-dutt-kolar.jpg`   | Mahesh Dutt Kolar   | Chief Executive Officer |
| `ratnadeep-mukherjee.jpg` | Ratnadeep Mukherjee | Co-Founder & Chief Revenue Officer |
| `gopinath-chandra.jpg`    | Gopinath Chandra    | Chief Operating Officer |

The three photos you shared map to these in the order supplied
(Mahesh → Ratnadeep → Gopinath).

No code change is needed — drop the files in and refresh. To add or reorder
leaders, edit `content/team.ts`.
